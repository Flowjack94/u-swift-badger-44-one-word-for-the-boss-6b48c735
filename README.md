## Entry

**Kraken** — one word describing the boss: a tentacle in every project
at once, dragging every deadline down into the deep without warning,
surfacing only to pull someone under.

## How it works

`main.py` validates the entry (a single word, 1–30 characters, valid
UTF-8) and writes exactly that word — nothing else — to
`/output/entry.txt`.

Run it with:

```sh
python3 main.py
```
